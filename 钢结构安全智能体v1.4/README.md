# 钢结构安全智能体 v1.3

双击本目录中的“启动程序.bat”启动，保留启动窗口；关闭窗口或按 Ctrl+C 停止服务。

顶部保留系统总览。四个主页面为实测快照、三维孪生、安全预测与预警、现场安全助手。

实测快照保留 S1～S10 十张卡片；卡片下方可选择测点，查看其最新记录日及前两天的应变和温度曲线。S4 缺测时显示提示。模型资料位于左侧公共侧栏的折叠区。

实测快照的监测卡片上方显示与“三维孪生”页相同的三维模型；模型、测点标记、悬浮信息和选中杆件高亮共用同一张图，同步施工阶段、材料、截面与测点配置。

实测快照和三维孪生不显示 MAT-WIRE16-FC（模型中记为 MAT_WIRE16_FC）的 34 根杆件，查询这些杆件时也不会高亮。其他页签保留完整模型，原始 MGT 文件及预测计算保持原有内容。

这两个页签默认使用实体钢管渲染，按 MGT 中的数值截面外径生成钢管，显示金属质感、光照和地面阴影。18 种钢管截面的外径比例保留；“管径显示倍率”默认为 2，设为 1 可查看真实外径比例，倍率不改变节点坐标或计算数据。“显示节点示意球”仅展示连接位置，不代表 MGT 中的实际连接节点构造。可旋转、缩放、平移，切换斜视/俯视/正视，悬停查询杆件或测点，并导出含测点编号的模型图片。侧栏保留“线框模型”供切换。替换模型中未提供支持的圆形截面尺寸的杆件保留为中心线。

实体渲染库 Three.js 0.180.0 随程序保存，运行时无需访问 CDN；来源和 MIT 许可证位于“static/steel-viewer”。安全预测与预警的模型恢复为最初的线框云图：深色绘图区、白色为主的细线、原版红蓝应力色标和黄色查询高亮。后加的钢材底色、加粗应力叠加、重点圆点和引线标签已移除。完整 CS18 几何、应力值、预警阈值和预测算法保持不变；色标仍在整个加载计划内一致。

监测数据已更新为本次提供的“商洛煤棚监测_应用数据.xlsx”：9 个测点、2322 条记录，最新时间为 2026-10-12 00:17:26。当前最近三天范围为 2026-10-10～2026-10-12，每个有数据的测点为 49 条记录；S4 保留缺测提示。

温度修正沿用旧数据表全部 3870 条公式中的方法：修正后应变＝应变变化值＋0.2×（温度－基准温度）。各测点使用原有基准温度。程序读取新数据时计算修正后应变，作为卡片默认“真实应变”及监测曲线的数据。原始 Excel 原样随包保存；已有修正值不会再次修正。参数与数据来源见“界面更新说明.md”。

标题栏保留深蓝底色 #0b1220，使用浅色标题及青色强调文字；其余界面采用白色背景，正文使用深蓝灰色，辅助文字使用深灰色，强调内容使用蓝色。侧栏、卡片、控件、监测曲线、预测图表和助手页面均适配白底。保留增大后的标题栏和字体、两排卡片间距，以及卡片上方的三维模型。重复的“实测快照”标题保持删除。中文使用微软雅黑，英文和数字使用 Times New Roman，覆盖侧栏、页签、表格、图表和助手内容。

本目录是独立版本，原程序及 v1.1、v1.2 均保留。详见“启动说明.txt”和“界面更新说明.md”。原版文档存放于“原版说明”，核对记录存放于“验证记录”。
