# DeepSeek 现场安全助手：开始使用

## 启动
完整解压压缩包，双击“启动整合界面.bat”。打开“现场安全助手”页。
原有应力预测与预警不需要 API 密钥，仍可独立运行。

## 配置接口
在“大模型连接设置”填写：
- 接口基础地址：https://api.deepseek.com
- 模型名称：deepseek-flash（按本次官方文档；后续以账号实际可用模型为准，可编辑）
- API 密钥：在你自己的 DeepSeek 开放平台账号创建，粘贴到密码框。
点击“测试连接”。页面只有测试成功才显示已验证。API服务费用按服务商规则产生；测试连接也会请求接口。
密钥仅存于当前会话，不写入文件或聊天。重启后需重新输入；也可设置 DEEPSEEK_API_KEY、DEEPSEEK_MODEL、DEEPSEEK_BASE_URL 环境变量后启动。本版不自动读取师兄的 .env，压缩包不包含真实密钥。
可配置兼容 Chat Completions 的 HTTPS 接口；不要填写 /chat/completions 后缀，程序自动追加。

## 三个快捷入口
1. 分析当前计划：实时调用本地 POD，读取整个计划的应力变化与控制梁端。
2. 解释当前预警：结合当前查看时点、计划点及实际界面演示阈值解释。
3. 复算加载进度减半：调用程序重新计算候选计划，展示依据；不自动修改原计划。
也可输入“查询杆件2081的变化”“保留80%的加载进度会怎样”。编号或比例不明确时要求补充，不猜测。
自由提问一般两次 API 调用：任务规划(JSON)→本地计算→文字解释；快捷入口使用明确路由，只调用一次文字解释。

## 计算与聊天一致性
本地结果直接作为本次回答证据[E1]，包含当前计划、阈值、时点、模型哈希、检验误差、控制梁端及必要的候选复算。
每条回答可展开和下载计算依据。仅发送相关摘要、问题与最近8条对话，不发送完整 Excel、MGT；数据将传输到所配置的服务商。
计划、阈值、模型或查看时点变化后自动清空旧对话。无有效预测时不能沿用历史结果。
最近对话仅保留在本次会话，未建立持久聊天数据库。

## 知识与边界
site_agent/knowledge.md 保存带[K1]～[K5]标识的项目事实、待核验事项和演示配置。它是小型项目知识直接注入，不是微调模型或向量检索系统。
模型预测与现场监测分开；默认2/3MPa仍是演示阈值；总应力与相对计划起点的应力变化分开。
不内置网络搜索，不支持通知发送、工单保存、自动修改阈值或批准施工/复工。
候选方案减少本时间窗工作量，不能称同工作量优化。没有完成实测校准、分区MGT核验及结构承载力验算。
大模型仍可能误读或产生不准确解释，管理人员应核对[E1]，不能据聊天结论直接作现场安全决策。

## 错误处理
连接超时、余额不足、密钥错误、模型名称错误会显示可读提示；不显示原始异常或密钥。每次请求超时30秒，不自动重试付费请求。计算模块不受接口故障影响。
