# 实测驱动重构使用说明

## 启动与更新

本次新增 sensor_reconstruction.py、reconstruction_ui.py 和 openpyxl 依赖，请解压完整项目再运行，不要只替换 app.py。
进入 steel_safety，双击 START_WINDOWS.bat。也可以执行：

```bat
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Python 3.13 可沿用原启动方式。原始模型、应力矩阵、POD基底文件和材料配色均保留。

## 先体验完整流程

1. 打开“实测驱动重构”。
2. 数据来源选“MIDAS 模拟数据演示”。
3. 保持默认参数，点击“运行实测驱动重构”。
4. 查看观测与重构对比、导出结果；切到“三维孪生”，悬停九个圆点查看新数值。
5. 选择其他模拟时刻后重新运行；CS13 基准时刻的重构增量应为零。

演示数据来自原 MIDAS 阶段应力，时间使用 2000 年的虚构标记，不是现场实测。S7/S8 的演示应变也仅由轴向应力换算，不能代表弯曲表面测量。

## 接入实测 CSV

必需列：time、sensor_id、strain_ue；temperature_c 在需要温度扣除时必填。应变单位为微应变 με，温度为 ℃。支持中文列名：时间、测点编号、应变、温度。
每行是一点一个时刻的读数。S4 不使用，测点保持 S1、S2、S3、S5、S6、S7、S8、S9、S10。空模板位于 data/reconstruction_template.csv。

选择实际目标时刻和施工阶段。目前支持 CS13～CS18。2026-09-05 对应 CS18 的既有记录可作为选阶段依据，其他时刻应按实际施工记录选择。
应变基准两种方式：
- 已相对 CS13 归零的增量：直接使用已做好共同基准和温度处理的机械应变增量。
- 原始读数：明确选取对应 CS13 的参考时刻，逐点计算当前值减参考值。程序不会自动把首条数据当作基准。若上传数据没有 CS13 参考读数，需要先完成基准对齐，或提供参考时段数据。

温度处理两种方式：
- 已完成温度补偿：程序不再扣除温度项，避免重复补偿。
- 按温度差扣除指定温度项：仅用于原始读数模式，逐点计算 Δε机械 = ε(t) - ε(ref) - k·[T(t)-T(ref)]。默认 k=12 με/℃ 来自附件热膨胀系数，实际适用性需要结合应变计自补偿、约束热应变和试验口径核验，不能把该近似当成普适的传感器修正。

默认弹性模量 E=206000 MPa，来自附件钢材定义。应力增量 Δσ = E·Δε机械·10⁻⁶，输出 MPa（N/mm²）。这一步采用线弹性且可对应纯轴向观测的假定。

采用每点不晚于目标时刻的最新读数，默认允许落后 60 s；可以修改该值，设为 0 则要求同一时刻。过期、缺失、重复、非法读数不会自动填零。基准时刻采用相同规则。

## 为什么当前使用七点求解

九个圆点全部保留；参与轴向系数求解的是 S1、S2、S3、S5、S6、S9、S10。
S7/S8 在报告中是弯曲测点，其表面应变不能直接等同纯轴向应变。它们显示输入的应变增量及模型估计的轴向响应（仅参考），不用于拟合，也不计算轴向观测残差。补充表面位置和弯曲响应/观测关系后才能正确纳入。
缺少部分轴向测点时按有效点重新选择参数；少于两个有效轴向点不求解。

## 算法与结果含义

取原矩阵 CS13 的梁端应力为基准 x₀，以 CS14～CS18 的差值构建增量快照 D=[x₁₄-x₀,…,x₁₈-x₀]，对 D 做 SVD，得到增量基底 U。此模块单独使用增量基底，不覆盖原十阶 pod_basis.npy。

设 H 选择有效测点的对应 I/J 端，y=E·Δε机械·10⁻⁶，则计算：

```text
A = H U_r
λ = α · s_max(A)²
a = argmin_a ||A a - y||² + λ ||a||²
Δx = U_r a
x_est = x_CS13 + Δx
```

实现通过小矩阵 SVD 求解，不对法方程求逆。α 是界面中的相对正则化参数。系数 a 描述相对 CS13 的变化，不是原均值中心化 POD 的绝对系数。

显示两类值：
- 重构轴向应力增量：相对共同基准 CS13。
- 估计轴向总应力：CS13 模型应力加重构增量；基准来自未完成现场校准的模型，不能把结果称作实测总应力。

仅对重构时刻所选阶段的活动梁端显示有效结果；未启用杆件输出空值和状态文字。结果覆盖有 POD 映射的 23838 个梁端，不包含无梁应力数据的其他单元。侧栏筛选只改变几何，结果时刻和阶段在悬停中独立标注。

## 验证结果与限制

自动选参在 CS14～CS18 上做五折留一阶段交叉验证，每折重新训练增量基底，被留出的阶段不进入该折基底训练。误差仅对该验证阶段的活动梁端计算。按假设 1 με 独立观测噪声（E=206000 MPa）的平均误差选择参数；它用于敏感性试验，不是仪器噪声实测值。

当前默认七点的推荐参数：4 阶，α=0.001。
- 无噪声留出阶段平均增量相对 L2 误差：23.40%。
- 最差阶段增量相对 L2 误差：51.87%。
- 假设 1 με 噪声的平均增量相对 L2 误差：25.27%。

这些值是参数选择用的交叉验证结果，不是独立最终测试，也不是现场准确率。验证矩阵仍只有五个 CS13 后阶段，且有构件逐步激活；应补充独立工况/现场留出数据，检查安装基准、表面弯曲、温度和测点位置偏差。程序保留“待评估”，不依据观测拟合残差给出结构安全等级。

详细参数结果：validation/parameter_comparison.csv；逐阶段结果：validation/stage_validation.csv。
已通过 10 项数值/数据测试，以及 Streamlit AppTest 的演示运行、三维悬停更新、参数失效处理、CS13 零增量和切换数据源测试。未实测本机浏览器的旋转帧率，未接入真实监测数据进行现场验证。
