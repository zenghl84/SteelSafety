# 临时数据异常筛查规则 v2

适用范围：本平台工作簿历史数据复核；不是结构承载力报警、设备量程判定或正式监测方案。原始数据不自动删除或修正。

- 应变：与该测点此前24小时内有效值的中位数比较，至少12条有效记录；偏离达到100με为关注，达到300με为重点复核。基线窗口随数据滚动，不代表已经确认正常的零应力基准，持续偏移被基线吸收是局限。
- 应变突跳：仅对相邻时间间隔大于0且不超过90分钟的两条有效记录比较；变化达到100με为关注，达到300με为重点复核。两项同时命中只按最高级计数。
- 温度：暂不设置临时筛查线或数值偏离/突跳判定，仅保留原始温度曲线、读数、时间联动、空值与记录间隔信息。
- 时间间隔：当前全历史中位间隔为60分钟。超过90分钟标记“记录间隔异常”，不是正式认定漏采条数；跨长间隔不判断突跳。
- 空值单列。没有命中规则显示“未触发暂定规则”，不显示“结构安全”。
- 100/300με、24小时窗口、12点最少样本和90分钟门槛均为本项目临时工程筛查参数，不是所收录规范原文限值，待监测方案、传感器精度、施工工况及设计模型确认后调整。
- 根据用户要求，新增绝对应变重点提醒：|应变变化值|≥1000με（包含正负及等于边界）时直接重点提醒，不受基线、样本数量、持续时长或突跳条件限制。排查仪器、测点安装、接线、量程、单位换算、零点偏置及实际结构受力；不能仅凭该阈值确定仪器故障或结构超限。1000με为项目暂定复核阈值，并非规范给出的通用限值。温度不应用此规则。不利用生成风速作真实荷载报警。

依据：GB50755-2012第15.2.5～15.2.9条提供异常复核及环境联动原则；T/CSCS033-2022监测初始值和预警值综合确定原则。GB50017-2017、GB50205-2020、GB55006-2021作为设计、验收、通用要求原文参考，不直接提供本项目筛查数值。

数据证据：S1在2026-10-15 01:17:26由-2581.855με跳至8314.395με，02:17:26回到-2587.839με。原因需检查采集设备、接线、量程/溢出、零点、换算及现场工况，不能仅凭尖峰确定为设备故障或结构损伤。
