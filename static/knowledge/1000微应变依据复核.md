# 1000με临时线依据复核（2026-10-17）

结论：未找到所查规范或对应厂家资料给出“应变绝对值达到1000με即为仪器故障”的统一结论。不能将其换为900με后宣称有规范依据。当前1000με属于尚待核定的人工关注阈值。

工作簿实际传感器型号为JMZX212HAT。厂家旧版JMZX-212HAT资料标注±1500με；厂家现有JMZX-212HAT/HB产品页标注±2500με。不同版本、预张力、安装状态和清零方式影响可用范围，须以现场序列号对应标定单和安装记录为准。量程不是结构允许应变。

T/CSCS033-2022相关说明要求监测初始值与预警值结合结构分析、监测前状态及环境变化确定。不能把未核实零点的表格值直接当作结构机械应变。

实际高疑点：S1于2026-10-15 01:17:26从-2581.855跳到8314.395με，后一条回到-2587.839με。此尖峰需优先排查采集、量程/溢出、单位换算、零点、接线及现场工况，但不能单独确定故障原因。

建议规则分三类：按现场确认量程判断数据有效范围；按同工况基线、噪声与变化速率筛查异常；按结构模型与材料/构件验算确定安全预警值。基线须经确认，不能把持续异常自动吸收为正常。

现场核验需要：各传感器标定单与版本、安装与清零记录、原始频率/原始读数、换算公式、温度修正口径，以及设计计算工况。
