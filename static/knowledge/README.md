# 本地知识资料

`catalog.json` 保存 v1.8 的资料编号、标题、摘要、原文位置和来源链接。两份 Markdown 文件保存项目暂定规则及依据复核。页面目前检索标题和摘要，不提供全文 OCR、向量检索或自动规范问答。

规范 PDF 为可选本地资源，默认不进入 Git。当前机器保留原文件；普通克隆中会显示“本地原文尚未安装”，其他功能仍可运行。

如果已取得相应原文并确认可以在本机使用，将文件放入本目录，保持以下名称，然后重新启动程序：

```text
钢结构工程施工规范GB50755-2012.pdf
钢结构工程施工质量验收标准GB50205-2020.pdf
钢结构设计标准(GB 50017—2017).pdf
钢结构通用规范GB 55006-2021.pdf
```

新增资料时同步更新 `catalog.json`。本地 URL 使用 `/app/static/knowledge/文件名`；外部来源使用完整 HTTPS 地址。索引中的原核对记录随 v1.8 保留，本次目录整理未重新验证条文或外部链接时效。
