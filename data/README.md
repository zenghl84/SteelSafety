# 数据文件说明

这里保留 v1.8 工作台当前使用的项目快照。文件来自原程序，不是通用模拟数据集。

| 文件 | 用途 |
| --- | --- |
| `model.mgt` | Gen 模型，提供节点、单元、材料与截面 |
| `sensor_mapping.csv` | S1–S10 测点与单元、端部位置的映射 |
| `商洛煤棚监测_应用数据.xlsx` | 应变、温度与时间历史，S4 缺失 |
| `stress_cs19.json` | CS19 两端四角组合正应力快照与模型哈希 |
| `assessment_config.json` | CS18 初始应力、确认表增量、材料基准、设备状态与来源 |
| `key_indicators_config.json` | 关键指标说明、演示参数和参考来源 |

`model.mgt` 与 `stress_cs19.json` 必须成套匹配，程序会核对原始模型字节的 SHA-256。不要转换 MGT 编码、换行，或手工改哈希绕过校验。替换模型时需重新准备匹配的结果和测点映射。

监测工作簿按测点工作表读取，必需列为：时间、传感器编号、传感器型号、测点名称、测点位置、应变变化值、单位1、温度、单位2。已有温补结果优先读取；否则按 `core/monitoring.py` 中的原基准温度和修正公式计算。新传感器不能直接套用旧设备基准。

缺测不补零；最新记录为空时不自动回退。损坏传感器保留历史和原映射值，同时退出有效评分。业务语义变更需同步修改配置、测试与文档。
