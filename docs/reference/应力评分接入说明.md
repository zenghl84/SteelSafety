# v1.8 应力评分接入说明

已接入首页“总体安全评估”和左侧“安全评估”页面，两处共用一套计算结果。

## 使用

打开本目录下：钢结构安全智能体v1.7 / 钢结构安全智能体v1.7 / 启动程序.bat。

默认来源为“已确认评分表”。S7、S8 按用户确认的同位置、同方向表面应力参与评分，均为 100 分。首页主分数为 9 点原映射平均参考分 82.4（含 S1 原映射 0 分）。S1 已由用户标记为传感器损坏，不参与有效测点受力判断；8 点有效均分为 92.7。原表没有采样时刻，界面已标明表格快照来源。

在左侧“安全评估”页可查看 9 点的初始应力、实测增量、估计总应力、材料基准、占用比及评分；下方有计算方法、分段规则和规范依据。可导出逐点计算 CSV。首页“查看详情”可进入本页；首页“导出报表”可导出当前来源摘要。

可切换“最新监测记录”，按工作簿各点最新记录的温补后应变乘 0.206 计算增量，再叠加 CS18 初始应力。首页同步更新，来源选择保存在当前浏览器。缺测不补零，超限保留原始数值并提示核验。

## 规则

总应力 = CS18 初值 + 实测增量；r = |总应力| / 材料基准。Q235B 暂取 215 MPa，Q355B 暂取 305 MPa。50%、70%、90%、100% 分别映射为 100、80、60、0 分，分段线性插值。分值映射为项目规则；当前为材料应力参考评分，受压稳定性、连接与疲劳仍需另行验算。
