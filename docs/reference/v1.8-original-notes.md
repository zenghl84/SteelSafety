# 钢结构安全智能体 · 监测数据工作台版

## 启动

解压到独立文件夹，双击 **启动程序.bat**。需要 Python 3.10 或更高版本。脚本优先复用已具备依赖的 Python，仅在没有可用环境时才安装依赖。保留启动窗口，关闭窗口即可停止。

页面以 1672×941 为设计尺寸，随浏览器视口等比适配。

## 文件位置

```text
app.py            页面入口
start.py          启动服务并打开浏览器
启动程序.bat      唯一的双击启动脚本
requirements.txt  必需依赖
core/             首页组装、模型解析、三维渲染、监测读取
assets/home/      页面 HTML、CSS、JS 和字体子集
assets/viewer/    本地三维资源与许可证
data/             Gen 模型、测点映射、监测工作簿
```

修改布局：`assets/home/style.css`；修改页面内容：`assets/home/index.html`；修改交互：`assets/home/app.js`；接入后端数据：`core/home.py`。

## 当前范围

首页样式、实体模型、历史应变曲线和模拟风速已接入。S4 保持缺失；损伤、疲劳与智能体区域为占位。安全评估已接入 CS18 安装基准的材料应力参考评分。彩色统计图是图形占位，不代表计算结果。

项目信息点击“编辑”后修改，保存到本机当前浏览器，可导出 JSON 配置。更换浏览器、清除浏览器数据或使用不同端口时，不保证共享该配置；该编辑不会修改原始监测数据或 Gen 模型。

模型工具：旋转/平移/缩放选择后用左键拖动；滚轮仍可缩放。剖切可选择 X/Y/Z 方向并调整位置。构件选择可点选或输入单元编号；隐藏可点击构件或隐藏已选构件；重置恢复隐藏与剖切。应力云图默认关闭，打开后显示CS19组合正应力绝对值，详见下方CS19说明。透明模式已接入实际材质。

此包只包含当前首页需要的代码与数据；旧界面、未引用的训练工况、验证图片、重复说明和缓存不包含在内。

三维依赖为 Three.js 0.180.0，遵循 MIT 许可证，见 `assets/viewer/LICENSE`。字体子集沿用 v1.4 自带字体。

三维模型背景为本地生成的荒漠场地：按当前钢结构边界保留浅色平整场地，外围为沙土、低矮灌木与草丛，远处为两层山脉与淡色天空。绿植共 360 簇，其中 230 簇集中在场地外围的近景区域，并避开结构外围的留白区；远山随视角变化，并在俯视检查时淡出。模型、测点标签与构件操作沿用原有数据和交互。环境代码位于 `assets/viewer/SiteEnvironment.js`，无需联网或下载图片。

## 知识库与临时筛查

知识库已收录4份本地规范原文、4条网上来源索引和项目暂定规则，可检索标题和摘要、打开原文；尚未实现全文OCR、向量检索或自动规范问答。静态PDF位于static/knowledge，通过Streamlit本地静态服务打开。

应变近期基线偏离或相邻有效记录突跳达到100/300με分别标记关注/重点复核；温度为5/10℃。基线及90分钟间隔规则见static/knowledge/临时预警规则.md。上述数字为项目暂定数据筛查值，不是规范结构安全限值。

规则v2：新增|应变变化值|≥1000με独立重点提醒，包含持续偏置、不受滚动基线影响；需排查仪器/测点/零点与实际受力，不直接判断故障原因。

温度暂不设置临时筛查线或数值异常判定，保留温度展示和联动；应变规则保持。


## CS19 计算应力云图

总览勾选“应力云图”。取每个单元 I/J 两端、Cb1～Cb4 四角组合正应力的绝对值最大值，整根杆件着色。固定范围 0～203 MPa，由蓝到红；灰色表示无结果。单击或悬停可查看两端绝对值最大值。CS19 / 合计 / 001(最后)，为静态计算快照，不随监测时间变化，不代表全工况包络或规范承载力验算利用系数。

数据来自梁单元应力CS19.xls，11919个单元、23838条端部记录，单元编号和端节点全部核对一致。全模型11953个单元，其中34个没有本表结果；原查看器仍按既有规则隐藏MAT_WIRE16_FC材料。data/stress_cs19.json保留两端四角有符号原始值、来源哈希和模型哈希。运行不需要xlrd或原XLS文件；原模型变化会拒绝加载此快照。

云图构件差异增强：按本份CS19结果的20%、40%、60%、80%分位点划分五级。蓝色0～7.7、青色7.7～14.7、绿色14.7～26.3、黄色26.3～46.1、红色46.1～203 MPa（左闭右开，最高级含203）。每种颜色约对应20%构件，扩大低应力区间的色彩差异，保留原始应力数据和MPa标签。分级用于比较相对应力，红色不代表超限。

连续云图更新：取消五级硬切换，在0/7.7/14.7/26.3/46.1/203 MPa色带锚点间连续插值；实体杆件根据I/J端四角组合正应力绝对值最大值计算端部颜色，并沿杆长线性混色。端间颜色是可视化插值，不代表新增计算截面或跨构件平均结果。节点相连构件仍保留各自端部应力差异。构件详情保留原始最大值。

## v1.8 应力评分

首页“总体安全评估”和左侧“安全评估”共用 core/assessment.py 的结果。默认显示用户确认的评分表：9 个测点均参与，S7、S8 的理论初值与实测增量已经确认是同位置、同方向的表面应力。首页显示原表 9 点平均参考分 82.4（含 S1 原映射 0 分）。S1 已由用户标记为传感器损坏，其当前有效评分留空，剔除有效受力判断；其余 8 点有效均分为 92.7。原表未提供采样时刻，不标作实时数据。

安全评估页可切换“最新监测记录”，按工作簿各点最新一条记录的温补后应变 × 0.206 换算应力增量，再与固定 CS18 初值叠加。沿用原表温度修正方法；不把空值补零，也不回退到较早的有效读数。各点时间在状态列显示。两种来源独立计算，切换后首页同步更新，浏览器记住上次选择。

规则：总应力 = CS18 初值 + 实测增量；r = |总应力|/材料基准。Q235B 暂取 215 MPa，Q355B 暂取 305 MPa。r≤50% 为 100 分；50%～90% 使用 150−100r；90%～100% 使用 600(1−r)；r≥100% 为 0 分。r 使用小数。首页主分数采用原映射平均参考分；有效测点均分剔除损坏设备与缺测。设备损坏单独记录，其他有效测点超限仍保留异常。

材料基准参考 GB 55006—2021 第 3.0.3 条及条文说明表 2，评分映射为项目规则。尚未纳入受压稳定性、连接与疲劳；正式现场限值需按监测方案和设计核定。本模块不将应力参考分直接等同于全结构安全鉴定。

配置见 data/assessment_config.json；前端见 assets/home/assessment.html、assessment.js 与 style.css。安全评估页可导出逐点计算 CSV，首页“导出报表”导出当前来源的评估摘要。

确认评分表下：最大材料应力比 0.761（S2，剔除损坏的 S1）；关键风险源为 2 个待复核项（S1 设备损坏、S2 应力关注）。应力比仅为有效测点参考值，并非全结构稳定及连接验算利用系数；复核项数量并非已确认结构损伤处数。

4 个演示指标：最大挠度 18.6 mm（虚拟位移 [0,-18.6,0] 的绝对值最大值）；疲劳损伤 0.120（假设 n=120000，N=1000000，D=n/N）；腐蚀 1 级（假设壁厚 6.0→5.8 mm，按平台演示阈值分级）；剩余年限 40 年（假设 50−10 的计划余量，不是项目真实寿命）。这 4 个数值与腐蚀阈值均为场景假设，不是规范给定值，不参与健康评分。

## 预警中心 · 关键风险源

左侧“预警中心”已接入首页同一组待复核项。界面由汇总卡片、来源/时间说明、可筛选风险清单和详情面板组成。默认确认评分表下有两项：S1 设备损坏（E11368 / J 端，用户于 2026-10-18 标记），S2 应力关注（E5545 / J 端，估计应力 −163.5729 MPa，应力比 76.08%，测点评分 73.9）。S1 不参与有效受力判断；原始留档可展开查看。

详情显示类别与待处理状态、测点位置、触发依据、计算过程、材料基准和项目暂定分界、影响说明、建议处置、采样时间/记录来源及规范链接。支持查看计算、监测历史、模型定位和导出完整风险说明。类型筛选包含设备故障、应力复核、缺测，清单不把每个风险源重复计数。

首页“关键风险源”卡片、风险记录、顶部通知和侧栏角标均可进入预警中心。中心的数据来源选择与安全评估页同步；若选最新工作簿记录，当前条目为 S1、S5、S6，不能继续固定显示两项。演示挠度、疲劳、腐蚀和寿命参数不生成这些预警，也不影响 82.4 分口径。

原确认表没有采样时间，系统也未记录首次触发时刻；界面分别显示“原表未提供采样时刻”和“触发时刻未记录”，不使用当前时间补造事件时间。S1 的 2026-10-18 是用户标记日期。状态当前为待检修/待复核，处置建议不代表现场工作已经完成。

算法见 core/alerts.py；界面见 assets/home/alerts.html、alerts.js 与 style.css；验证见 tests/test_alerts.py。材料基准参考 GB 55006—2021 第 3.0.3 条及说明表 2；70%/90%/100% 是本项目暂定筛查分界，正式预警值结合工程监测方案核定。异常检查与维护原则参考 GB 50982—2014 第 3.4.5、3.4.7、3.4.8 条。
