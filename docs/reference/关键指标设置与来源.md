- 类型：有效点计算。
- 数据来源：已确认评分表；data/assessment_config.json 与对应应力增量。
- 计算：max(|σ|/f)；控制点 S2，E5545 / J：|-163.5729| / 215 = 0.760804。
- 说明：此处是有效测点材料应力比，不是全结构包络或含受压稳定、连接的规范验算利用系数。S1 损坏，已排除。

- 参考方法/原则：[GB 55006—2021 第 3.0.3 条及条文说明表 2](https://gf.cabr-fire.com/m/article-39049.htm)。材料强度设计值依据；不提供本项目统一监测报警阈值。

## 最大挠度：18.6mm

- 类型：演示值。
- 数据来源：本次演示场景假设，data/key_indicators_config.json。
- 计算：虚拟节点竖向位移 [0, -18.6, 0] mm，参考值 0 mm；取相对位移绝对值最大值。
- 说明：三个虚拟示意节点；支座基准取零。不是本项目 MIDAS 节点或位移结果。 18.6 mm 不是规范给出的值，也不是模型求解结果。
- 正式评估需补充：同工况节点竖向位移、支座参考及测量基准；应变不能直接替代全结构挠度。
- 参考方法/原则：[GB 50017—2017 附录 B.1](https://gf.cabr-fire.com/m/article-34710.htm)。挠度容许值的参考；不提供本项目实测挠度，未据此判定示例合格。

## 疲劳损伤指标：0.120

- 类型：演示值。
- 数据来源：本次单级循环演示场景假设，未从监测应力谱计算。
- 计算：D = Σ(nᵢ/Nᵢ)；此示例取 n=120000、N=1e+06，D=0.120。
- 说明：单级应力谱的演示假设；循环数与容许循环数均非监测结果，未指定项目 S-N 曲线。 n、N 和 D 均非规范给定的项目数值。
- 正式评估需补充：足够采样的应力历史、连接细节类别、S-N 曲线参数及累计循环次数。
- 参考方法/原则：[GB 50017—2017 第 16.2 节及 16.2.3 条文说明](https://gf.cabr-fire.com/m/article-34694.htm)。应力谱、连接类别和 S-N 参数；条文说明介绍 Miner 累积损伤。

## 腐蚀等级：1级

- 类型：演示分级。
- 数据来源：本平台演示分级及假设测厚，非现场检测结论。
- 计算：假设原始壁厚 6 mm、剩余 5.8 mm；厚度损失率=3.33%，演示映射为 1 级。
- 说明：平台演示分级：厚度损失率≤5%为1级，>5%～10%为2级，>10%～20%为3级，>20%为4级；不是规范腐蚀分级。
- 正式评估需补充：现场测厚、原始壁厚、涂层/锈蚀检查及适用的评定规则。
- 参考方法/原则：[GB 55006—2021 第 2.0.1、2.0.4 条](https://gf.cabr-fire.com/m/article-39044.htm)。设计工作年限与防腐维护原则；不提供本平台演示腐蚀分级和剩余寿命数值。
