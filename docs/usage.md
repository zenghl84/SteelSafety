# 使用指南

## 安装与启动

安装 Python 3.10 或以上版本，推荐 3.12。克隆后在仓库根目录安装 `requirements.txt`，运行 `start.py`；Windows 可以直接双击 `启动程序.bat`。完整命令见[项目首页](../README.md#快速开始)。

启动器仅监听本机 `127.0.0.1`，自动选择 8501–8520 内的空闲端口，并在健康检查通过后打开浏览器。可通过 `--port 8502` 指定端口，通过 `--no-browser` 禁用自动打开浏览器。终端显示当前地址，按 `Ctrl+C` 停止。

```bash
python start.py --check
python start.py --no-browser --port 8502
```

运行日志位于 `.logs/streamlit.log`，此目录不进入版本控制。所有项目资源都相对源文件定位；从其他工作目录调用 `start.py` 时，启动器仍会使用仓库根目录。

## 页面操作

### 总览与三维模型

鼠标拖动旋转模型，滚轮缩放。工具栏支持平移、缩放、按 X/Y/Z 剖切、点选或按单元编号选择构件，以及隐藏和重置。测点标签可结合监测页面定位到模型构件。

应力云图默认关闭。开启后显示 CS19 快照的端部组合正应力绝对值，颜色沿杆件插值，范围为 0–203 MPa；灰色表示该表没有结果。红色表示色带高值，不能直接解释为超限。

项目信息可编辑并导出 JSON。编辑结果保存在当前浏览器，不会改写 `data/` 中的模型、工作簿和测点映射。浏览器或端口变化时可能需要重新导入或编辑。

### 监测数据

选择多个测点，对比应变或温度历史；可选近 1/7/30 天、全部历史或自定义区间。游标联动显示选中时刻的数据，支持 CSV 导出、测点详情与总览模型定位。

工作簿空值和尖峰保留。S4 没有历史记录；S1 保留历史曲线并显示设备损坏状态。有效值占比基于已记录单元格，不等于计划采样完整率。

风速通过系统设置中的参数生成器生成。参考动压使用 `q = 0.5 × 1.225 × v² / 1000`，单位 kPa，尚未计入结构设计风荷载的其他系数。

### 安全评估与关键指标

安全评估可切换“已确认评分表”和“最新监测记录”。前者为已确认快照；后者使用各测点最新一条记录的温补后应变换算增量，并叠加 CS18 初值。最新记录缺测时保持缺测，不回退至旧值。

首页主分数保留原 9 点平均参考分 82.4；S1 损坏后不参与有效受力判断，其余 8 点均分为 92.7。详情和导出同时区分原映射分、有效评分、设备状态与数据来源。

“关键指标”支持“现有数据 / 演示参数”切换。演示挠度、疲劳、腐蚀和剩余年限不会改变评分和预警。页面可导出逐点计算 CSV、当前评估摘要和指标来源说明。

### 预警中心与知识库

预警中心与首页共用风险来源，可筛选设备故障、应力复核和缺测。默认确认评分表下有 S1、S2 两项待复核；切换监测来源后按该来源重算。

知识库检索标题、摘要和编号。外部来源需要网络；本地 PDF 是可选资源，未安装时显示提示。安装方式见[本地资料说明](../static/knowledge/README.md)。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 找不到 Python | 安装 Python 3.10+；Windows 推荐安装 Python 3.12 并启用启动器 `py` |
| 依赖安装失败 | 在虚拟环境中重新执行 `python -m pip install -r requirements.txt`，检查 PyPI 网络连接 |
| 没有自动打开浏览器 | 使用终端显示的本机地址手动打开 |
| 指定端口不可用 | 换用 `--port` 指定其他端口，或让启动器自动选择 |
| 模型与 CS19 结果不匹配 | 使用同一模型生成的快照；不要单独修改模型原始字节或强行绕过校验 |
| 克隆后没有 PDF | 按本地资料说明放入原文；其他模块无需 PDF 即可运行 |
| Linux 中文字体不同 | 系统安装可用中文字体；页面优先使用系统字体，也支持可选本地字体子集 |
