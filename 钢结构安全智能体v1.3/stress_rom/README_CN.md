# CS13—CS18 应力增量降阶代理：今天的操作顺序

本包已准备 MIDAS 工况副本、历史基准应力，以及训练、独立检验、预测和网页预览程序。
新增工况需要在你的 MIDAS GEN 2026 中分析。包内尚无训练完成的代理，也没有虚构的 MIDAS 应力结果。

预测量与 CS13 为应变监测基准相匹配：

\[
\Delta\sigma=\sigma_{CS18}-\sigma_{CS13},\qquad
\Delta\varepsilon_{轴向}(\mu\varepsilon)=\frac{\Delta\sigma(\mathrm{MPa})}{E(\mathrm{MPa})}\times10^6.
\]

应力云图显示带符号的 Δσ（MPa），测点表附轴向应变估算。现有 9 个测点所在杆件都已在 CS13 激活。
现有测点映射将 S7、S8 标为弯曲测点，它们不能用“轴向应力/E”来比较弯曲表面应变。

## 现在先准备 CS13 参考表与 case_080

1. 解压整个文件夹到本机。保留 `source/model.mgt` 作为原始模型。
2. 使用 `文件 → 导入 → midas Gen MGT 文件`，将 `midas_cases/case_080.mgt` 导入一个新工程，另存为 `case_080.mgb`。不要把它叠加导入已有工程。
3. 该文件已经将“施工活荷载”工况下“施工荷载组18”的 83 条竖向节点荷载乘以 0.8。节点 1 的 FZ 为 -522.496 N，原值为 -653.12 N。无需再乘一次倍率。
4. 保留原有施工阶段顺序完成分析。核对计算信息；存在不收敛或机构问题时先处理模型问题，不导出无效结果。
5. 用基准 `case_100.mgt` 另外导出一次参考应力表：选 CS13、最后一步 `001(last)`、`合计(CS)`、梁单元、I/J 两端、Pos-1、轴向应力，存为 `results/CS13_reference.xlsx`。倍率组18在 CS13 尚未激活，所以该参考表可供全部倍率工况共用。
6. 从 `case_080.mgt` 导出 CS18 同类结果，保存为 `results/case_080_CS18.xlsx`。
7. 两表都尽量保留至少 3 位小数及单元、荷载、阶段、步骤、位置、成分和带单位的应力列。

导入界面名称可能随 MIDAS 版本不同。使用 MGT 文本导入功能；若导入失败，保留提示信息，不改写求解器控制项来强行通过。

## 训练会做什么

1. 读取一次 `CS13_reference.xlsx` 和每份倍率工况的 CS18 表，识别中英文表头，筛选合计(CS)、最后一步及 I/J 端。
2. 按单元编号和 I/J 端对齐，逐端计算 `Δσ = σ(CS18) − σ(CS13)`。只有当 MGT 阶段表确认某梁端在 CS13 尚未激活时，才允许把该端 CS13 应力按零处理；CS13 已激活端若缺结果会报错。
3. 只对 0.8、1.0、1.2 的 Δσ 快照进行中心化 POD；按平方奇异值累计能量 99.9% 截断。
4. 在荷载倍率与 Δσ 的 POD 系数之间做一维分段线性插值。
5. 用未参与 POD 和插值拟合的 0.9、1.1 结果做检验，保存误差及增量峰值位置。

三个中心化训练快照最多产生两个非零模态。如果固定模型在该范围内接近线性，只有一阶很正常；多算同一荷载分布的倍率不会自动形成多种独立受力模式。
本方法是“应力 POD + 非侵入式插值代理”，没有实施 PPT 中的位移型 Galerkin 刚度投影。它不需要位移表或刚度矩阵。
网页应力云图和预测 CSV 表示轴向应力变化 Δσ，单位 MPa。对轴向测点，可用对应材料弹性模量估算模型应变增量：`Δε(με)=Δσ(MPa)/E(MPa)×10^6`。这让模型量与以 CS13 为基准的应变增量处于可比较的量纲，但仍需按传感器实际位置、方向和测点定义匹配。S7、S8 在现有映射中为弯曲测点，不能用上述单轴换算代替弯曲表面应变计算。当前网页提供测点位置的模型估算，不会自动读取或配对用户的实测时间序列。

## 怎样看输出

- `trained/stress_rom.npz`：可供网页或其他 Python 程序加载的代理。
- `trained/validation_metrics.csv`：0.9、1.1 两个独立工况的误差。
- `trained/validation_report.json`：方法、数据来源、文件哈希、完整误差及适用范围。
- `trained/pod_energy.csv`：应力变化的 POD 累计能量；这不是“预测准确率”。

RMSE 和最大绝对误差的单位为 MPa。`relative_l2` 是误差向量范数/实际 Δσ 向量范数，例如 0.01 表示 1%。
`load_effect_relative_l2` 用“相对 1.0 倍率工况的实际 Δσ 变化”作分母，更容易发现恒载或既有施工阶段应力占主导时，被全场相对误差掩盖的问题。
分母接近零时记为空值，不把它记成 0% 误差。另有真实/预测最大绝对应力所在梁端、最不利端部重合情况。
程序不会自动把某个误差阈值认定为工程合格标准。先核对全场、局部最大误差和关键杆件；仅受拉单元可能随荷载改变工作状态，误差较大时需要增加采样或分区建模。

仅想导出倍率 1.05 的预测：

```powershell
python rom.py predict --lambda-value 1.05
```

结果在 `predictions`。程序拒绝超出训练倍率区间的预测；倍率不是时间，当前模块不自动预测未来荷载。

## 接入原网页

保留原平台布局，在其后端加载本模型即可。最小调用如下：

```python
from rom import load_model, prediction_table
model = load_model('trained/stress_rom.npz')
field = prediction_table(model, 1.05)
# field 包含 element、position、delta_stress_mpa、
# predicted_axial_delta_strain_microstrain 以及工况元数据。
# 杆件上色可选 I/J 端 |Δσ| 较大者并保留正负号；明细保留两端。
```

网页的核心响应已经是 CS18−CS13 的 Δσ；不应再对预测值减一次 1.0 倍率基准。若要与实测应变增量比较，按测点配对并对轴向测点用其弹性模量换算。对同一测点的实测值，需先确认它的零点确实定义为 CS13。
